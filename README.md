## Important Note

This demo URL is currently served through a temporary Cloudflare Tunnel. It will
only work while the local frontend, backend, MySQL database, and tunnel
processes are running on the host machine.

For a permanent public URL, deploy the frontend and backend to cloud hosting and
move the database to a managed MySQL service.
